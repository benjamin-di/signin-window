# Security

A login service built with this package shows a real browser, signed in or signing in to someone's account, to
whoever holds a link, and hands the session to a server. Please report anything that could let someone other than
the link's holder see or drive a window, reach the login service without its bearer or a window without its view
token, get a session out of a link or the page, keep a window off its site, or make the package automate a sign-in,
privately through GitHub's
[private vulnerability reporting](https://github.com/benjamin-di/signin-window/security/advisories/new) rather than
in a public issue.

Only the latest release is supported.
